# 🥟 Dapure Nduk

Website *landing page* resmi untuk **Dapure Nduk** – spesialis sajian Dimsum dan Mentai Rice/Shirataki premium buatan rumah (*homemade*). 

Dibuat untuk mempromosikan kelezatan dimsum berbahan daging udang & ayam segar pilihan, 100% tanpa bahan pengawet, dan halal.

## ✨ Fitur Website
- **Desain Modern & "Women-Friendly":** UI dirancang elegan dan kalem (perpaduan kuning pastel hangat & ungu tua logo) dilengkapi efek animasi halus.
- **Katalog Menu Interaktif:** Daftar lengkap varian menu (Mentai & Dimsum) dengan detail harga.
- **Pemesanan Mudah:** Tombol "Pesan via WhatsApp" (*Click-to-Chat*) yang otomatis mengisi format pesanan, memudahkan pembeli.
- **Testimoni Kekinian:** Ulasan pelanggan disajikan dengan desain unik ala Instagram Story.
- **Responsif:** Tampilan menyesuaikan secara otomatis (tetap rapi) saat dibuka di HP, Tablet, maupun PC.

## 💻 Teknologi yang Digunakan (Tech Stack)
Website ini dibangun dengan menggunakan teknologi website terkini dan super cepat:
- **[Next.js (App Router)](https://nextjs.org/)** - Framework React untuk performa maksimal.
- **[Tailwind CSS](https://tailwindcss.com/)** - Styling desain secara cepat dan konsisten.
- **[Framer Motion](https://www.framer.com/motion/)** - Membuat animasi *scroll* dan transisi menjadi hidup.
- **[Lucide React](https://lucide.dev/)** - Kumpulan ikon minimalis.

## 🚀 Cara Menjalankan (Local Development)

Pastikan Node.js sudah terinstal di komputer Anda. Lalu buka terminal/CMD, arahkan ke folder ini, dan jalankan perintah:

```bash
# 1. Install semua paket (hanya jika baru pertama kali / pindah komputer)
npm install

# 2. Jalankan server lokal
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di *browser* Anda untuk melihat hasilnya secara langsung. Setiap kali Anda mengubah kode, *browser* akan otomatis memperbarui tampilannya.
